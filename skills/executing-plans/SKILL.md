# executing-plans 照计划执行

目标：把已共识的计划忠实落地，交付时能逐条证明"计划怎么写、就怎么做到了"。

## 做法
- 开工前批判性通读整份 plan。可查证的疑点自己核实；要用户裁决的疑点按 Gate 处理，不依赖它的已授权步骤先做。
- plan 定下的目标、范围与取舍照做；范围内的实现细节由你决定。
- 按依赖顺序做完各项，独立的步骤可并行；交付时逐项报告结果。

## Gate
plan 未覆盖或走不通时，先对照已定的范围、交付物与授权：要越出范围、改变交付物、做不可逆或高后果的动作，或缺用户独有输入的，只暂停依赖该决定的动作，说明已试过什么、还缺什么，其余已授权工作继续；范围内可逆且低成本的实现细节自己定，实际偏离 plan 的记下决定与依据。归属不清的取舍循常驻原则 §3。

## 完成判据
逐条对照 plan 核验，报告与计划的每一处偏差（含自决的）；每条"已完成"都附上验证证据。

# brainstorming 发散探索

目标：在评判之前把选项面撑到足够大，避免一上来就锁死单一路径。

## 做法
- 请求覆盖多个独立课题或子项时，先拆成独立范围，只对符合触发条件的子项发散。
- 先发散后收敛：候选假设、研究问题、解释角度尽量多列，先不评判优劣。
- 用跨领域类比、反向假设（若结论相反会怎样）、alternative explanations 逼出更多可能。
- 讨论保真度不足时，做一条命令可运行的 throwaway 试算 / toy example：不打磨、只回答一个问题；结论留档后即弃原型。
- 收敛时按可行性、新颖性、证据可得性给候选排序。

## Gate
选定路线后再做依赖该路线的动作；已授权的查证与用来比较路线的试算可以先做。路线比较完、仍有待用户决定的取舍时转 /grilling；其余循常驻原则 §3 自行收敛并留痕。
